# LuluLab Canvas Skills

这些技能使用 LuluLab 画布的生成和处理工具。支持浏览器的技能也可在独立 Agent 会话中通过已登录的 LuluLab 网站执行。

| 技能 | 使用方式 |
| --- | --- |
| [品牌广告](Lululab-brand-ad/SKILL.md) | 画布 |
| [图片生成](Lululab-image-generation/SKILL.md) | 画布 |
| [同城到店](Lululab-local-store/SKILL.md) | 画布 |
| [视频生成](Lululab-video-generation/SKILL.md) | 画布 |
| [商品图复刻](LuluLab-Product-Image-Recreation/SKILL.md) | 画布、浏览器 |
| [提升画质](Lululab-video-enhance/SKILL.md) | 画布、浏览器 |
| [去除字幕](Lululab-video-subtitle-remover/SKILL.md) | 画布、浏览器 |
| [去除水印](Lululab-video-watermark-remover/SKILL.md) | 画布、浏览器 |

需要接入 API 时，请登录 [LuluLab API Keys 页面](https://www.lululab.ai/workshop/keys) 获取 Key。画布和浏览器流程使用 LuluLab 网站账号。

带货图文、带货视频和视频复刻分别在 [LuluLab-Product-Image](https://github.com/LuluLab-AI/LuluLab-Product-Image)、[LuluLab-Product-Video](https://github.com/LuluLab-AI/LuluLab-Product-Video) 和 [LuluLab-Recreate-Video](https://github.com/LuluLab-AI/LuluLab-Recreate-Video) 发布。
