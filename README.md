# LuluLab Canvas Skills

这些技能使用 LuluLab 画布的生成和处理工具。支持浏览器的技能也可在独立 Agent 会话中通过已登录的 LuluLab 网站执行。

| 技能 | 使用方式 | 独立下载 |
| --- | --- | --- |
| [品牌广告](Lululab-brand-ad/SKILL.md) | 画布 | [下载 ZIP](https://github.com/LuluLab-AI/LuluLab-Canvas-Skills/releases/download/v1.0.0/Lululab-brand-ad-v1.0.0.zip) |
| [图片生成](Lululab-image-generation/SKILL.md) | 画布 | [下载 ZIP](https://github.com/LuluLab-AI/LuluLab-Canvas-Skills/releases/download/v1.0.0/Lululab-image-generation-v1.0.0.zip) |
| [同城到店](Lululab-local-store/SKILL.md) | 画布 | [下载 ZIP](https://github.com/LuluLab-AI/LuluLab-Canvas-Skills/releases/download/v1.0.0/Lululab-local-store-v1.0.0.zip) |
| [视频生成](Lululab-video-generation/SKILL.md) | 画布 | [下载 ZIP](https://github.com/LuluLab-AI/LuluLab-Canvas-Skills/releases/download/v1.0.0/Lululab-video-generation-v1.0.0.zip) |
| [商品图复刻](LuluLab-Product-Image-Recreation/SKILL.md) | 画布、浏览器 | [下载 ZIP](https://github.com/LuluLab-AI/LuluLab-Canvas-Skills/releases/download/v1.0.0/LuluLab-Product-Image-Recreation-v1.0.0.zip) |
| [提升画质](Lululab-video-enhance/SKILL.md) | 画布、浏览器 | [下载 ZIP](https://github.com/LuluLab-AI/LuluLab-Canvas-Skills/releases/download/v1.0.0/Lululab-video-enhance-v1.0.0.zip) |
| [去除字幕](Lululab-video-subtitle-remover/SKILL.md) | 画布、浏览器 | [下载 ZIP](https://github.com/LuluLab-AI/LuluLab-Canvas-Skills/releases/download/v1.0.0/Lululab-video-subtitle-remover-v1.0.0.zip) |
| [去除水印](Lululab-video-watermark-remover/SKILL.md) | 画布、浏览器 | [下载 ZIP](https://github.com/LuluLab-AI/LuluLab-Canvas-Skills/releases/download/v1.0.0/Lululab-video-watermark-remover-v1.0.0.zip) |

按需下载单个 ZIP，解压后保留完整技能文件夹。使用 LuluLab 网站内置画布时，可直接在画布里选择技能。仅支持画布的技能依赖 LuluLab 画布工具。

需要接入 API 时，请登录 [LuluLab API Keys 页面](https://www.lululab.ai/workshop/keys) 获取 Key。画布和浏览器流程使用 LuluLab 网站账号。

带货图文、带货视频和视频复刻分别在 [LuluLab-Product-Image](https://github.com/LuluLab-AI/LuluLab-Product-Image)、[LuluLab-Product-Video](https://github.com/LuluLab-AI/LuluLab-Product-Video) 和 [LuluLab-Recreate-Video](https://github.com/LuluLab-AI/LuluLab-Recreate-Video) 发布。
