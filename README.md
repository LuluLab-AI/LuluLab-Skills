按需下载单个 ZIP。解压后保留完整技能文件夹。使用 LuluLab 网站内置画布时，可直接在画布里选择技能。仅支持画布的技能依赖 LuluLab 画布工具。

需要接入 API 时，请登录 [LuluLab API Keys 页面](https://www.lululab.ai/workshop/keys) 获取 Key。画布和浏览器流程使用 LuluLab 网站账号。

带货图文、带货视频和视频复刻的独立项目与历史版本见 [LuluLab-Product-Image](https://github.com/LuluLab-AI/LuluLab-Product-Image)、[LuluLab-Product-Video](https://github.com/LuluLab-AI/LuluLab-Product-Video) 和 [LuluLab-Recreate-Video](https://github.com/LuluLab-AI/LuluLab-Recreate-Video)。
